# Atoms Smart Switch

Smart switch retrofit module based on ESP-IDF.

## Version 1 goal
- 1 or 2 channel first
- relay output
- manual switch input
- local wireless control
- offline operation
- safe PCB architecture
- low cost

## Repository structure
- firmware/  -> ESP-IDF firmware
- hardware/  -> schematic, PCB, hardware notes
- docs/      -> architecture, API, test plan
